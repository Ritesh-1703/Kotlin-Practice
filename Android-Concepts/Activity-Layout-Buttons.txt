Activity kya hoti hai?

Activity ek single screen hoti hai jo user ke saath interact karti hai.
Jaise:
Login Screen
Home Screen
Settings Screen
👉 Har screen = ek Activity

Activity ka kaam
UI show karna
User input handle karna
Dusri Activity open karna
App lifecycle manage karna


Lifecycle flow:
1️⃣ onCreate()
Activity create hoti hai
XML layout yahin attach hota hai
2️⃣ onStart()
Activity visible hoti hai
3️⃣ onResume()
User interact kar sakta hai
4️⃣ onPause()
Activity partially hidden (call, dialog)
5️⃣ onStop()
Activity fully hidden
6️⃣ onDestroy()
Activity memory se remove

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)
    }
}


- Layout XML (UI ka Blueprint 🏗️):- 
Layout XML file UI ka structure define karti hai.
📁 Location:
res/layout/activity_main.xml

Common Layout Types:- 
.......................
1️⃣ LinearLayout:- 
Items ek line me (vertical/horizontal)
<LinearLayout
    android:orientation="vertical"
    android:layout_width="match_parent"
    android:layout_height="match_parent">
</LinearLayout>

2️⃣ RelativeLayout:- 
Views relative position me

3️⃣ ConstraintLayout (🔥 RECOMMENDED):- 
Flexible, fast, modern
<Button
    android:id="@+id/btnClick"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    app:layout_constraintTop_toTopOf="parent"/>

🔹 View IDs ka role
android:id="@+id/myButton"
👉 Kotlin me access:
findViewById<Button>(R.id.myButton)
🔹 Expert Level XML Tips:- 
✔ ConstraintLayout performance best
✔ Hardcoded text mat likho → strings.xml
✔ Dimensions → dimens.xml
✔ Dark Mode support rakho

State Selector Example: -
................................

9️⃣ Prevent Multiple Clicks (Expert Tip 🔥):- 
...............................................
🔹 Debounce Button Click
btnLogin.setOnClickListener {
    btnLogin.isEnabled = false
    // API call
    btnLogin.isEnabled = true
}


OR

var lastClick = 0L
btnLogin.setOnClickListener {
    if (System.currentTimeMillis() - lastClick < 1000) return@setOnClickListener
    lastClick = System.currentTimeMillis()
}
