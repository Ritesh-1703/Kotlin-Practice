Fragment and FragemntLifeCycle:- 
.....................................

Fragment Android ka most important UI component hai, especially modern apps (single-activity architecture) me.
Fragment ek reusable UI + logic ka piece hota hai jo Activity ke andar live karta hai.
👉 Fragment Activity ke bina exist nahi kar sakta.
Examples:
Screen ka ek part (Header, List, Bottom section)
Tabs (Home, Profile, Settings)
ViewPager pages

2️⃣ Fragment kyun use karte hain? 🤔:- 
........................................
| Reason          | Explanation                          |
| --------------- | ------------------------------------ |
| Reusability     | Same fragment multiple activities me |
| Modularity      | Clean & maintainable code            |
| Single Activity | Modern architecture                  |
| Tablet support  | Multi-pane UI                        |


3️⃣ Fragment vs Activity (IMPORTANT 🔥):- 
..............................................
| Activity            | Fragment              |
| ------------------- | --------------------- |
| Independent         | Activity pe dependent |
| Heavy               | Lightweight           |
| App entry point     | UI part               |
| Manifest me declare | Manifest me nahi      |

6️⃣ Fragment Lifecycle (MOST IMPORTANT 🔥🔥):- 
.................................................

🧬 Fragment Lifecycle Methods (Order)
onAttach()
onCreate()
onCreateView()
onViewCreated()
onStart()
onResume()

--- Fragment Active ---

onPause()
onStop()
onDestroyView()
onDestroy()
onDetach()

🔹 onAttach():- 
✔ Fragment Activity se attach hota hai
✔ Context milta hai

🔹 onCreate():- 
✔ Non-UI initialization
✔ ViewModel setup

🔹 onCreateView():-
✔ XML inflate hota hai
✔ View create hoti hai

🔹 onViewCreated() (VERY IMPORTANT 🔥):- 
✔ View binding
✔ Click listeners
✔ UI logic
override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
    super.onViewCreated(view, savedInstanceState)
}

🔹 onStart():- 
✔ Fragment visible

🔹 onResume():- 
✔ User interaction possible

🔹 onPause():- 
✔ Save state
✔ Stop animations

🔹 onStop():- 
✔ Fragment hidden

🔹 onDestroyView() (CRITICAL ⚠️):- 
✔ View destroy hoti hai
✔ Binding null karo
override fun onDestroyView() {
    super.onDestroyView()
    _binding = null
}

🔹 onDestroy():- 
✔ Fragment destroyed

🔹 onDetach():- 
✔ Activity se detach

..............................................

val viewModel: SharedViewModel by activityViewModels()

🔟 Fragment Arguments (Data Passing):- 
........................................
