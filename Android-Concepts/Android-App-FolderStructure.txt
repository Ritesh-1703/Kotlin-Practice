ROOT LEVEL (Top Level): -
..............................

MyApplication/
│
├── .gradle/
├── .idea/
├── build/
├── gradle/
├── app/
├── build.gradle (Project)
├── settings.gradle
├── gradle.properties
└── gradlew
1️⃣ .gradle/
✔ Gradle ka cache
✔ Build performance fast karta hai
✔ Kabhi manually edit mat karo

2️⃣ .idea/
✔ Android Studio ke internal settings
✔ Git me mostly ignore hota hai

3️⃣ build/
✔ Auto-generated files
✔ APK, intermediates, outputs

4️⃣ gradle/
gradle/
 └── wrapper/
     ├── gradle-wrapper.jar
     └── gradle-wrapper.properties
✔ Ye ensure karta hai ki same Gradle version sab machines pe chale

5️⃣ gradlew
✔ Gradle wrapper executable
✔ CI/CD pipelines me use hota hai

Types of Dependencies:- 
.............................
| Type                  | Use            |
| --------------------- | -------------- |
| implementation        | Normal use     |
| api                   | Library expose |
| testImplementation    | Unit test      |
| debugImplementation   | Debug only     |
| releaseImplementation | Release only   |
